# PHASE 4 — 회원 탈퇴, 기기 데이터 보호, 개인정보 안내

## A. 회원 탈퇴

상태: **서버 RPC(0007) 로컬 검증 + 클라이언트 화면 구현 / 원격 미적용**

### 절차
1. 설정 › 계정 › "회원 탈퇴" 펼치기
2. 경고(서버 데이터 영구 삭제) + 이 기기의 **미전송 변경 수** 표시 → 필요하면 먼저 내보내기
3. 재인증: 비밀번호 사용자는 비밀번호 입력(→ `signInWithPassword` 로 `last_sign_in_at` 갱신). 소셜 사용자는 로그아웃 후 다시 로그인하고 10분 안에.
4. `탈퇴` 입력 → `rpc('delete_my_account', { p_confirm: 'DELETE' })`
5. 서버: 본인 확인 → 10분 내 로그인 확인 → 관리자 아님 확인 → `auth.users` 삭제 → 모든 표 cascade (한 트랜잭션)
6. 성공 후 기기: **그 계정의 레코드·대기열·충돌·백업·동기화 커서만** 삭제(`purgeOwnerData`) → 이 기기 로그아웃. 같은 기기의 로그인 전 데이터·다른 계정 데이터는 보존.

### 삭제 순서와 실패
| 단계 | 실패 시 |
|---|---|
| 재인증 실패 | 서버 호출 안 함 (테스트 PUB-DEL-001) |
| RPC: 10분 초과 | `reauth_required` → 아무것도 삭제 안 됨 |
| RPC: 삭제 중 오류 | 트랜잭션 롤백 → 계정·데이터 모두 그대로 (부분 삭제 없음) |
| RPC 성공, 기기 정리 전에 창 닫힘 | 서버는 삭제됨. 기기 데이터는 남지만 다음 로그인 시 그 계정으로 로그인 불가 → 사용자가 '이 기기 데이터 지우기'로 정리 가능 |
| RPC 미배포 | `not_deployed` 안내 |

### 보존 데이터
- DOTDAY 자체 보존 데이터 없음(로그·운영 기록 표 없음).
- Supabase 내부 Auth 감사 로그·플랫폼 백업의 보존 기간은 Supabase 정책을 따른다 → **법률 자문 필요 항목**.
- 다른 회원 데이터는 삭제되지 않는다 (테스트 SEC-DEL-001: B 의 행 수·내용 동일).

## B. 이 기기 데이터 지우기 (`src/app/deviceData.ts`, 설정 화면 맨 아래)

- 서버 계정·데이터는 건드리지 않는다. 탈퇴와 다른 버튼·다른 설명.
- 지우기 전 요약: 업무 레코드 수, 다른 계정 데이터 수, **미전송 변경**, 충돌, **서버에 없는 로그인 전 데이터**.
- 미전송·충돌·로그인 전 데이터가 있으면 기본 차단 → 동기화 또는 내보내기 안내 → "사라지는 것을 확인했습니다" 체크 후에만 가능. 함수 자체도 `acceptLoss` 없이 호출되면 거부(이중 방어).
- 로그인 상태면 지운 뒤 이 기기에서 로그아웃(Supabase 세션 제거) → 새로 고침.
- IndexedDB 버전(2)·스토어 구조는 그대로. 스토어를 비우기만 하므로 DB 마이그레이션이 필요 없다.
- 계정 전환 시 노출: 기존 구현이 `owner_id` 로 화면을 거른다(테스트 DEV-003). 저장소에 남은 사본은 이 기능으로 지운다.

## C. 개인정보 안내 (`#privacy`, `#terms`)

- 수집 항목: 이메일, 인증 정보(Supabase 보관), 소셜 제공자 식별자·이메일·프로필, 사용자가 입력한 업무 데이터, (켜면) Turnstile 브라우저 신호.
- 위탁: Supabase(DB·인증), Vercel(호스팅), 메일 발송 서비스, Cloudflare(CAPTCHA).
- 권리 행사: 내보내기·수정·삭제·탈퇴를 앱 안에서 직접.
- 문의처: `VITE_CONTACT_EMAIL` 설정 시 표시 (현재 비어 있음 → "준비 중").
- 서버의 삭제 표시(tombstone) 행이 내용과 함께 남는다는 점을 사실대로 적었다.

### 법률 자문 필요 항목 (임의로 준수를 보장하지 않음)
1. 개인정보 보호법상 처리방침 필수 기재 사항(처리 목적·보유 기간·파기 절차·안전성 확보 조치·책임자) 충족 여부
2. 국외 이전(Supabase·Vercel·Cloudflare 서버 위치) 고지·동의 필요 여부
3. 만 14세 미만 가입 처리
4. 가입 시 약관 동의 방식(현재 "가입하면 동의한 것으로 봄" 문구) 적정성
5. Supabase 백업·감사 로그 보존 기간과 파기 고지
6. 소셜 제공자별 개인정보 제3자 제공·위탁 고지
