### 브라우저 검증 중 발견해 수정한 문제
1. **기본 보기 중복 생성**: React StrictMode와 여러 컴포넌트가 동시에 `listViews`를 호출해 도메인마다 기본 보기가 2개 생겼다. 확인과 생성을 한 readwrite 트랜잭션에서 하도록 고쳤다(`ensureDefaultView`). 회귀 테스트도 추가했다.
2. **머리글 드래그 순서 변경**: HTML5 DnD가 자동화 입력과 터치에 반응하지 않았다. 포인터 이벤트 방식으로 다시 구현했고, 실제 마우스 드래그로 동작을 확인했다.
3. 자동화 테스트에서 발견: 큐 쓰기에서 예외가 나도 트랜잭션이 중단되지 않아 **레코드만 저장되는** 문제가 있었다. 명시적으로 `abort`하도록 고쳤다(VIEW-011 원자성 테스트).
